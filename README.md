# Resume Source

This repository contains the LaTeX source used to generate my resume.

## Files

- `resume.tex` — editable LaTeX document

## Build

Compile with a LaTeX distribution such as TeX Live or MiKTeX:

```bash
pdflatex resume.tex
```

Run the command again when needed to resolve references and produce the final PDF.

## Editing

The document uses standard LaTeX packages for page layout, section headings, hyperlinks, lists, and multi-column skills formatting. Update the source and rebuild the PDF after changes.
